# DSDP SALI LCF - Discrete Structure Detection Pipeline

## Overview
This project, DSDP SALI LCF, operationalizes "morphic" as latent structure detectability rather than an ontological field. It quantifies persistence (temporal waves), coherence (FSI), and predictive discrete structure (next-band prediction). Validation relies strictly on conservative nulls, ablations, perturbations, and kill-switch rules. The project aims for "Echo<Fresh" as an anti-contamination outcome, not as evidence for non-local transfer. Its core ambition is to provide a robust framework for detecting and validating discrete structures within complex data, with implications for understanding underlying patterns in various scientific domains.

## System Architecture
The pipeline is structured around detecting discrete structures within embedding data.
### UI/UX Decisions
The project emphasizes clear visualization of results through various plots generated by `plots.py`, including calibration outputs, full pipeline outputs, and phase 1 hypothesis test outputs. Outputs are provided in JSON and plot formats for easy interpretation.
### Technical Implementations
- **Data Loading and Validation**: `data_loader.py` handles loading, validation, and normalization of fresh and echo embeddings.
- **Geometric Analysis**: `geometry.py` identifies anchor pairs, hubs, and magistrales using spherical k-means.
- **Lattice Scoring**: `lattice.py` implements log-space lattice scoring with a dual grid and coupler mechanism.
- **Temporal Analysis**: `temporal.py` calculates S(t) scores, wave persistence, and FSI.
- **Null Models and Ablations**: `nulls.py` generates various null models (uniform, gaussian, spacing) with Holm correction, while `ablations.py` performs targeted seed, coupler, anchor, and temporal ablations.
- **Perturbation Analysis**: `perturbation.py` is used for generating perturbation curves and detecting tipping points.
- **Metrics**:
    - `entropy.py`: Calculates per-bin residual entropy, alignment entropy, and magistrale entropy.
    - `wave.py`: Extracts wave profiles and per-bin wave signals.
    - `identity.py`: Computes identity vectors using Hungarian label alignment and coupling strength.
### Feature Specifications
- **Hypothesis Testing**: The project tests hypotheses such as H1 (Coherence Threshold), H2 (Peripheral Coupling), and H5 (Intentional Abort) using dedicated experimental harnesses.
- **Calibration System**: A comprehensive 10-test calibration pack ensures reproducibility and validates against various synthetic data conditions (RANDOM_PURE, NEAR_NULL, REAL_NORMAL, REAL_SURVIVAL, REAL_BIBLICAL).
- **Anti-Axial Abort Mechanism**: H5 utilizes a deterministic anti-alignment operator to target well-aligned points, move them to maximally misaligned positions, and add PCA-axis jitter, preserving angular structure while breaking radial alignment.
- **Fractal Verification**: Calibration adjustments are verified for scale-invariance across time, space, and regime.
- **Boundary Polymorphism**: Analyzes topological score separation and component/Euler transitions across various conditions and thresholds.
### System Design Choices
The architecture promotes modularity, with distinct scripts for data generation, calibration, pipeline execution, and hypothesis testing. The use of configuration files (`config.yaml`) allows for flexible parameter adjustment. Output management is structured into dedicated directories (`outputs/calib`, `outputs/full`, `outputs/phase1`).

## External Dependencies
- **NumPy**: For numerical operations, especially with embeddings (`.npz` files).
- **sentence-transformers/all-MiniLM-L6-v2**: A BERT-based model (384 dimensions) used for real neural network validation, specifically for generating sentence embeddings from scientific English text.
- **ONNX**: Used for inference with the BERT-based model.
